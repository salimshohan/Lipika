## 🌟 Overview

**Lipika (লিপিকা)** is a modern, high-performance input method editor (IME) engineered for fast and elegant typing on Android. Built with modern Android architecture using **Jetpack Compose** for a fluid UI, bundled with an ultra-responsive **Rust native core** for spatial touch prediction and instant phonetic transliteration.

---

## ✨ Key Highlights

- **⌨️ Perfected English Layout & Bengali Numeral Hints**:
  - Dedicated Number Row (`1`–`0`) displaying Bengali numerals (`১`–`০`) as secondary hints on top-right corners; normal tap types English digit, long-press inserts corresponding Bengali numeral.
  - Refined symbol hints on QWERTY alphabet keys (`q`→`৳`, `w`→`%`, `e`→`_`, `r`→`;`, `t`→`<`, `y`→`>`, `u`→`+`, `i`→`=`, `o`→`[`, `p`→`]`, `a`→`@`, `s`→`#`, `d`→`&`, `f`→`*`, `g`→`-`, `h`→`!`, `j`→`?`, `k`→`(`, `l`→`)`, `z`→`"`, `b`→`'`, `n`→`:`, `m`→`/`).
  - Clean `x`, `c`, `v` keys without distracting badges, featuring intuitive direct Cut, Copy, and Paste on long-press (Copy automatically copies entire text if nothing is highlighted, or selected text when highlighted).
  - Streamlined bottom row order: `?123` ➔ `Emoji` ➔ `Comma (,)` ➔ `Spacebar` ➔ `Full Stop (.)` ➔ `Go / Enter`.
- **🎨 Dedicated Appearance Section**: Comprehensive appearance controls with Display Mode (Light, Dark, System Default), App Theme (Light, Dark, System, Dynamic Color), Keyboard Theme (Light, Dark, Custom with live interactive preview), Dark Style (Pure Black `#000000`, AMOLED `#18181B`, Dark Gray `#22242B`), and Scheduling (Always Light, Always Dark, Sunset to Sunrise, Custom Schedule with time sliders).
- **🎛️ Modern 4×2 Dashboard Grid**: Smart Typing, Fonts, Theme, Language, Preferences, Clipboard, Appearance, and About in rectangular frosted glass cards.
- **⚡ Smart Typing Intelligence**: Consolidated Smart Typing with offline bilingual (Bengali & English) emoji predictions and corrections.
- **🔤 Font Studio with Tw Cent MT & 11+ Fonts**: Built-in real TTF typography selection including **Tw Cent MT**, **Kalpurush (বাংলা)**, Segoe UI, Georgia, Consolas, Candara, Comic Sans, Trebuchet MS, Verdana, Calibri, Corbel, plus direct custom font file loader (`.ttf` / `.otf`).
- **✂️ Direct Cut, Copy & Paste Shortcuts**: Integrated shortcuts directly on the English keyboard:
  - **`x` key**: Cut (✂️)
  - **`c` key**: Copy (📋)
  - **`v` key**: Paste (📄)
  - **`z` key**: Select All (🔘)
- **⚡ Super Speed & Low Latency**: Fine-tuned touch latency and spatial distance matching for seamless typing.
- **🔒 Privacy First & 100% Offline**: Zero analytics, zero tracking, completely offline.

## ⌨️ Curated Language Layouts

Lipika features 5 carefully chosen layouts:

| Layout | Description |
|---|---|
| **English (QWERTY)** | Standard English keyboard with direct copy/paste shortcuts and number flicking. |
| **বাংলা (প্রভাত)** | Popular fixed traditional Bengali layout for fast typing. |
| **বাংলা (অভ্র)** | Intuitive phonetic typing (`ami` → `আমি`) powered by the native engine. |
| **Arabic (العربية)** | Standard Arabic layout with full Harakat diacritics. |
| **বাংলা (জাতীয়)** | Official National BSTI layout standard. |
