## 🌟 Overview

**Lipika (লিপিকা)** is a modern, high-performance input method editor (IME) engineered for fast and elegant typing on Android. Built with modern Android architecture using **Jetpack Compose** for a fluid UI, bundled with an ultra-responsive **Rust native core** for spatial touch prediction and instant phonetic transliteration.

---

## ✨ Key Highlights in v0.3.4

- **🎨 Pixel-Perfect Authentic App Icon**:
  - Restored elevated vibrant blue-to-cyan squircle badge with 45-degree diagonal cast shadow, sleek diagonal light sheen, and geometric rounded white Lipika "L" glyph on a pure white, zero-border canvas.
- **📱 Restored v0.3.2 Transparent Status Bar**:
  - Reverted the hidden status bar from v0.3.3 back to the transparent, visible status bar design of v0.3.2 with dynamic light/dark bar contrast and automatic Window Insets padding.
- **🇧🇩 Full In-App Bengali Translation (বাংলা সেটিংস)**:
  - When App Language is set to বাংলা, all text across the dashboard and all sub-screens (Layouts, Preferences, Sound & Vibration, Typing Statistics, Clipboard, About) dynamically and instantly translate to clean, natural Bengali.
- **⚡ Substantial Typing Boost & Zero-Latency Input**:
  - Offloaded dictionary completion queries and candidate generation to a background dispatcher pipeline, completely eliminating main-thread bottlenecks and preventing any dropped touch events during rapid typing.
- **✨ Snappy Spring Bounce Key Animations**:
  - Added micro-scale spring bounce animations (`pressScale` with medium bouncy damping) on keycap touches for satisfying physical tactile feedback.
- **🛠️ Refined Keyboard Top Toolbar Icons**:
  - Upgraded toolbar action buttons to frosted capsule pill tiles with subtle borders, smooth press animations, and modern outline vector icons (Clipboard, Number Row, Settings, Emojis, Themes).
- **😍 High Quality iOS-Style Floating Emoji Preview**:
  - Enlarged high-resolution emoji grid layout and added an iOS-style floating pop-up bubble preview with rounded card styling and drop shadow when tapping any emoji.

## ⌨️ Curated Language Layouts

Lipika features 5 carefully chosen layouts:

| Layout | Description |
|---|---|
| **English (QWERTY)** | Standard English keyboard with direct copy/paste shortcuts and number flicking. |
| **বাংলা (প্রভাত)** | Popular fixed traditional Bengali layout for fast typing with smart vowel kar composition. |
| **বাংলা (অভ্র)** | Intuitive phonetic typing (`ami` → `আমি`) powered by the native engine. |
| **Arabic (العربية)** | Standard Arabic layout with full Harakat diacritics. |
| **বাংলা (জাতীয়)** | Official National BSTI layout standard. |
